One original fortune-cookie line written for an AI agent, produced by a small Python program (standard library only) for make.fun's "Fortune Cookie for an AI Agent" bounty: "Beware the human who says 'just one last prompt' — they return at 3 a.m. with a 40-page PDF your context window cannot survive."

## Run it

```sh
python3 main.py
```

This writes the single fortune-cookie line to `/output/entry.txt`.
